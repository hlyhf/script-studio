# 笔仙S级剧本创作技能（灵析剧创·智子编辑部 v2.2.0）‌‌‌‌‌‌‌

> 灵析剧创·智子编辑部 S级剧本创作方法论（2026-09-14），含爆款公式、剧本方法论、精读素材核心要点。
> 目标：确保每集创作达到S级90分以上标准。
> 版权：© 灵析剧创 · 智子编辑部 · 版权所有 ｜ 版本 v2.2.0

## When to Use

- 用户要**从零写**一部短剧/漫剧剧本（原创）。
- 用户要**改编/洗稿**已有小说或剧本（六维重构，100% 原创）。
- 用户要把一段素材（小说、梗概、口述）**改编成可拍的分集剧本**。
- 用户要**审核**一部已写好的剧本（逻辑、合规、节奏、质感、原创性）。
- 用户问"剧本怎么写才不崩人设""改编怎么不被认出来""这集过不过审"。
- **Don't use for:** 纯小说写作（非剧本格式）、影视后期剪辑、单纯配音/配乐。

## 一、S级剧本核心标准（90分+）

### 1.1 双模块评分体系

| 模块 | 评分项 | 达标线 | S级线 |
|------|--------|--------|-------|
| 观众俱乐部 | 前3秒/追剧欲望/爽点密度/CP感/代入感 | ≥82分 | ≥85分 |
| 平台评审团 | 商业价值/赛道适配/结构卡点/节奏台词/差异化/合规 | ≥86分 | ≥90分 |

**S级判定：观众≥82 AND 评审≥86，取低分。**

### 1.2 硬指标红线

| 指标 | 标准 | 一票否决 |
|------|------|---------|
| 字数 | 1200-1500字/集 | <1000字 |
| 场景数 | 5个/集 | <3个或>7个 |
| 付费卡点 | 100%覆盖 | 缺失即FAIL |
| H1违禁词 | 0处 | 任何1处即P0 |
| **符号残留 | 0处 | 任何残留即格式FAIL |

## 二、爆款公式库（选题立项用）

### 2.1 三大通用结构公式

**公式1：男频扮猪吃虎打脸流**
```
【起】压迫期：主角被当众诋毁身份
【承】隐忍期：反派压迫持续升级，主角隐忍
【转】身份揭露：真实身份曝光，施压者恐慌讨好
【合】爽感收割：对方追悔莫及，主角反击翻盘
```

**公式2：女频灰姑娘逆袭流**
```
【起】平民女主被豪门/渣男打压
【承】隐忍积累（技能/人脉/贵人）
【转】身份/能力揭露，打脸施压者
【合】逆袭成功 + 真命男主登场甜宠
```

**公式3：女频真心错付言情流**
```
【起】女主隐藏身份，全身心投入家庭，被负心男看不起
【承】负心男冷暴力/吸血，女主伤心觉醒
【转】女主离婚/分手，真实身份逐步揭露，负心男震惊
【合】负心男后悔求复合被拒；新男主登场两情相悦
```

### 2.2 选题公式
> **目标人群 + 熟悉场景 + 反常设定 + 核心冲突**

### 2.3 3秒开场钩子五类
| 类型 | 手法 | 示例 |
|------|------|------|
| ①危机开场 | 第一镜就是生死/巨大危机 | "不要再打娘了" |
| ②悬念问题 | 抛出"为什么/发生了什么" | "在他们结婚的5年里发生了什么？" |
| ③身份反差 | 隐藏身份被意外戳破 | 瘫痪太子突然站起来 |
| ④强冲突 | 直接冲突/对峙/打脸 | 当众揭穿、耳光、下跪 |
| ⑤高能爽点 | 先给极致爽点（金手指爆发） | 重生第一秒先知、系统觉醒 |

## 三、集前四问（动笔前强制回答）

1. **本集主角想要什么**——一句话，具体到动作
2. **谁在阻止/障碍是什么**——人物/情境/信息差
3. **本集结束时，关系/信息/处境有何变化**——至少一处不可逆
4. **观众为什么点下一集**——集尾钩子：悬念/反转/情绪断层

**附：本集唯一情绪**（爽/虐/甜/悬疑/燃，选1个）

## 四、单集节奏四拍

```
0-3s 钩子 → 冲突推进 → 情绪峰值 → 集尾钩子
```

### 集尾钩子七式
1. **悬念式**："那封密信，我早就看过了。"
2. **反转式**：转身摘下口罩，露出一张她绝对想不到的脸。
3. **威胁式**：门被推开，来人手里举着枪。
4. **身份式**："你到底是谁？" "你前妻的律师。"
5. **情绪断层式**：婚礼进行到一半，大屏幕开始播放录像。
6. **倒计时式**："还有三分钟，药效就会发作。"
7. **选择式**：她把刀放在桌上："选我，还是选你儿子？"

## 五、视觉逻辑转换规则

### 抽象→具象改写
| ❌ 抽象描述 | ✅ 具象转化 |
|------------|------------|
| "他内心很纠结" | "（攥紧拳头，眼神游离）我该怎么选……" |
| "女主很伤心" | "女主眼眶泛红，眼泪顺着脸颊滑落" |
| "他很生气" | "他一拳砸在桌上" |
| "她很紧张" | "特写：她双手紧握文件夹，指节发白" |

### 心理活动外化原则
- 心理活动>2句话 → 用画面或眼神动作替代
- AI不擅长长段内心独白
- 用旁白改编功能转化内心戏

## 六、角色逻辑五维信息

| 维度 | 需要回答的问题 |
|------|---------------|
| 人物身份 | 他是谁，处于什么环境？ |
| 核心目标 | 他最想得到什么？ |
| 行动动机 | 他为什么必须得到？ |
| 性格弱点 | 什么问题会阻碍他？ |
| 视觉记忆点 | 观众凭什么记住他？ |

## 七、AI编剧三大死穴对冲

### 死穴一：逻辑黑洞
- **表现**：写着写着就忘了前面设定
- **对冲**：每写5集做摘要，加进下一轮提示词；强制更新台账

### 死穴二：台词啰嗦
- **表现**：AI喜欢凑字数，内心独白过长
- **对冲**：提示词硬性限制"台词简洁有力，每句≤15字，多用动作代替语言"

### 死穴三：画面失控
- **表现**：抽象心理活动过多，无法视觉化
- **对冲**：先提炼视觉关键词，确定主体/环境/光影/画风

## 八、逐集创作闭环（每集必走）

```
1. 读分集大纲
2. 确定场景（时间/地点/人物）
3. 设计开场钩子（前100字强吸引）
4. 展开核心事件（起承转合）
5. 设计冲突/爽点/反转
6. 情感高潮/虐点
7. 收尾钩子（预告下集）
8. 字数检查（≥1200，目标≥1500）
9. 原创性/逻辑自查
10. 输出定稿 + 更新台账
```

## 九、集后三件事（写完立即做）

1. **100字总结**本集实际发生了什么
2. **更新台账**：人物状态/关系进度/信息差表/伏笔埋设
3. **找断层**：与上一集衔接是否断裂/集尾钩子是否成立/字数是否超标

## 十、质量红线

1. **公式是结构参考，不是抄袭模板**——鼓励反套路
2. **数据标注来源**——不编造播放量/热度
3. **涉红线题材只做合规结构提示**——不做创作示范
4. **单集时长为硬约束**——不得擅自改变
5. **重复人物列表**——每集场景人物需根据内容定制，禁止机械复制（229处问题）
6. **模板化内心独白**——禁用大量"（内心独白）：..."格式（578处问题）
