# 3 秒开场钩子方法论（hooks-3sec.md）‌‌‌‌‌‌‌

> 用户核心需求："如何 3 秒吸引人"。本文提供开场钩子五类 + 自检清单。
> 原理：短视频/短剧的第一性 = 前 3 秒制造"冲突"打破平静，利用好奇心驱动完播（海外素材营销逻辑）。

## 五类开场钩子
| 类型 | 手法 | 示例 |
|---|---|---|
| ① 危机开场 | 第一镜就是生死/巨大危机 | "不要再打娘了"（疯美人）、斩首当天 |
| ② 悬念问题 | 抛出一个"为什么/发生了什么" | "在他们结婚的5年里发生了什么？"（Playlet） |
| ③ 身份反差 | 隐藏身份被意外戳破的瞬间 | 瘫痪太子突然站起来、壮汉男扮女装报名 |
| ④ 强冲突 | 直接冲突/对峙/打脸 | 当众揭穿、耳光、下跪 |
| ⑤ 高能爽点 | 先给一个极致爽点（金手指爆发） | 重生第一秒先知、系统觉醒 |

## 0-3s 结构设计（四步）
1. **画面**：一个高信息量、有张力的画面（不要 logo/片头/空镜）
2. **首句台词**：一句带钩子的台词（悬念/冲突/宣言）
3. **冲突**：0-3s 内制造"平静被打破"
4. **勾子**：给观众一个"必须看下去"的理由（下个悬念/身份反转预告）

## 3 秒自检清单（写完开场后逐条过）
- [ ] 0-3 秒内是否有画面冲击/台词钩子/冲突？
- [ ] 首句台词是否可成为"传播金句"？（参考"我是你的狗"）
- [ ] 是否打破平静（不是日常闲聊开场）？
- [ ] 结尾是否埋了"集尾钩子"（下集预告/悬念）？
- [ ] 是否符合该题材公式的开场惯例但又有差异？

## 单集节奏四拍（拆解/创作通用）
0-3s 钩子 → 冲突推进 → 情绪峰值 → 集尾钩子
（每集都要有"饿"的感觉，好剧集让观众觉得饿，而不是满意）

## 集尾钩子八类型（参考 short-drama-takedown rhythm-formulas）
身份反转预告 / 危机升级 / 金句宣言 / 新角色登场 / 悬念提问 / 背叛揭露 / 爽点爆发 / 下集高能预告
