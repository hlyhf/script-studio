> 标注钩子、单集节奏、全集结构时对照使用。全网多来源汇编，共识高度一致。

## 一、单集节奏公式（5 种）

**公式 1 · 按秒法则**：0-3s 黄金钩子（极限冲突，绝不铺垫）→ 4-10s 信息密度（身份/核心矛盾/终极悬念）。

**公式 2 · 60 秒情绪微循环**：0-20s 紧张建立/升级 → 20-50s 情绪峰值（每 15s 一次反转/打脸/悬念）→ 50-60s 钩子切断（在冲击点切断，不在余韵点）。

**公式 3 · 单集节奏（抖音编剧）**：热开场 5s → 情绪变化/第一次升级 15s → 再次升级 15s → 期待感 10s → 期待感反复 3 次×10s → 爽点兑现+留钩子 10s。

**公式 4 · 1 分 30 秒留存版**：0-3s 视觉冲击（3%）→ 3-10s 冲突前置（8%）→ 冲突升级 → 反转 → 钩子。

**公式 5 · 万能一句话**：黄金 3 秒开场钩子 + 快速抛出核心冲突 + 全程情绪过山车 + 结尾卡死强钩子。短剧与长剧相反：情绪优先、冲突密集、钩子不间断。

## 二、黄金结构四模块

1. **开门杀（0-5s）**：一句话+视觉强刺激，开篇即冲突。四种句式：反差句/悬念句/情绪句/身份压制句。
2. **三段式钩子递进（5-15s）**：信息反转 → 动机暴露 → 关系张力，三连钩让观众"没看懂全部信息"而停留。
3. **情绪峰值（15-25s）**：价值观被逼到边缘；男频爽点/权力逆转，女频情绪撕裂/暧昧张力。
4. **小反转收尾（25-30s / 45-60s）**：抛出更大谜。**铁律：观众觉得"满意"就切晚了，应该觉得"饿"。**

## 三、5 种开场钩子公式

身份逆转钩（最低谷↔最高点）/ 绝境钩（两难无解）/ 隐藏身份钩（猎秘本能）/ 倒计时钩（紧迫时限+严重后果）/ 惊天揭露钩（颠覆信息重构认知）。

## 五、黄金开场三角公式

**强势人设 + 极致冲突 + 悬念钩子 = 黄金开场**

- **强势人设**：身份标签 + 极端困境 + 第一反应（用行为定义人设，不靠旁白）。
- **极致冲突**：当下发生的灾难；有立刻代价（尊严/关系/生存）；绑定人物关系（人对人博弈，非纯事件）。
- **悬念钩子**：话说到一半 / 动作卡点 / 反转预告 / 时间限制 / 观众视角介入。

## 六、三大题材黄金结构

- **逆袭复仇**：被欺压→开挂变强→实力碾压→逆天改命。分段：1-5 集建立不公（压抑→愤怒）→ 6-10 集转变（期待）→ 11-40 集系统复仇（爽感密集）→ 41-60 集终极 Boss（紧张）→ 61-80 集终局（爆发→释然）。
- **甜宠**：身份反差开场 → 男主表面冷拒实则心动 → 每集一个心动瞬间 → 集末误会/吃醋钩子。
- **悬疑**：开场即案发/失踪/反转 → 信息缺口 → 主角被迫入局 → 悬念层层递进。

## 七、三段式框架（爆款共识）

**压抑铺垫 → 获得金手指/身份转折 → 反杀打脸**。爆款简介高频词：意外/穿越/逆袭/守护/系统/阴谋。
