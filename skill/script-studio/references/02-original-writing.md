# 参考 02 · 原创剧本创作 + 逻辑性规划

原创剧本最容易翻车的不是文笔，而是**逻辑硬伤**：人设崩塌、时间线打架、伏笔烂尾、动机不成立、职业细节穿帮。本文件给出"先锁逻辑再写细节"的方法，并定义本 skill 独有机制 **L0 逻辑·合理双轴预审** 在成稿前的自检用法（L0 的正式流程与阈值见 `references/04`）。

---

## 一、立项与目录（原创简化版）

```
[项目名]/
├── 00-项目信息/        第00集剧本信息 + 逻辑锚点表
├── 01-大纲/            60集总纲 + 三段式分集大纲
├── 02-分集剧本/        _drafts/（迭代）+ 第XX-XX集_全本.md
├── 03-质量检查/        逐集评分表 + P0/P1/P2清单
└── 04-交付/            最终docx（封面/目录/分页/配色）
```

---

## 二、逻辑规划：逻辑锚点表（动笔前必建）

这是**独有机制的核心载体**。动笔前先填一张表，把"故事为什么成立"锁死，写作时逐集回扣，避免写到后面忘记前面。

| 锚点类 | 必填字段 | 作用 |
|--------|----------|------|
| **核心冲突** | 主线冲突一句话（有动词）+ 副线冲突 | 全剧不跑题 |
| **主角动机弧** | 起点目标A → 终点目标B，每10集的位移 | 成长线可追 |
| **反派动机** | 反派要什么 + 为什么（不是"因为坏"） | 动机成立 |
| **伏笔清单** | 每枚伏笔：埋设集数 → 计划回收集数 → 回收方式 | 100% 回收，断头即P0 |
| **时间线基准** | 故事起点日期/事件 + 关键节点绝对时间 | 时间线自洽 |
| **能力/权力边界** | 每个关键角色能/不能做什么（防开挂） | 合理性轴 |

**伏笔清单模板：**
```
| 伏笔ID | 内容 | 埋设集 | 回收集 | 回收方式 | 状态 |
|--------|------|--------|--------|----------|------|
| F1 | 母亲遗物玉佩 | 03 | 41 | 真相揭露时出示 | open |
| F2 | 男主左手疤 | 05 | 28 | 身份识别关键 | open |
```

**完成标准：** 6 类字段全填，伏笔清单每个 open 项都有计划回收集数，无空项。

## 三、三幕/三段式结构

| 段落 | 集数 | 定位 | 情感曲线 |
|------|------|------|----------|
| 第一段 | 01–20 | 相遇·建立关系·初步冲突 | 压抑→希望 |
| 第二段 | 21–40 | 深入·危机加剧·情感升温 | 希望→危机 |
| 第三段 | 41–60 | 对决·高潮·结局 | 危机→新生 |

每集大纲必含：集标题、场景设定、出场人物、核心事件(1–3)、情感节点(爽/虐/反转)、钩子设计。

---

## 四、逐集创作十步（每集必走）

```
1 读分集大纲
2 确定场景（时间/地点/人物）
3 设计开场钩子（前100字强吸引）
4 展开核心事件（起承转合）
5 设计冲突/爽点/反转
6 情感高潮/虐点
7 收尾钩子（预告下集）
8 字数检查（≥1200，目标≥2000）
9 原创性/逻辑自查（对照锚点表）
10 输出定稿
```

**每集自检清单：**
- [ ] 字数 ≥1200（<1000 一票否决）
- [ ] 场景头/人物行/△/对白齐全
- [ ] 前100字有强钩子
- [ ] 结尾 🔒 卡点 + ▶️ 下集预告
- [ ] 无任何原版痕迹（原创天然满足）
- [ ] 情感有起有伏
- [ ] 本集事件不违反逻辑锚点表（动机/时间线/能力边界）

## 五、逻辑·合理双轴自检（写作中随用，成稿后入 L0）

写作中每写完 5 集，对照锚点表做"双轴快查"：

**逻辑轴（Logic）—— 有哪些会让人出戏？**
- 时间线：本集时间与基准时间是否矛盾？前后集是否同日同地却隔了 improbable 时长？
- 动机：角色本集行为是否服务于其已声明的动机？有无"为剧情方便突然变卦"？
- 因果：事件A是否真的导致事件B？有无"天降解决"？
- 伏笔：本集是否埋了新伏笔却忘了登记？已埋伏笔是否到了计划回收集？
- 人设：行为是否符合小传性格？有无 OOC（out of character）？

**合理轴（Reason）—— 经不起推敲的细节？**
- 职业/行业：术语准确吗？工作流程符合现实吗？（医生不开违背医理的方）
- 权力/能力边界：主角是否突然获得未铺垫的能力/资源？（防开挂）
- 情感反应：震惊/悲伤/背叛后的反应符合人性吗？有无"秒原谅/秒黑化"？
- 物理/社会常识：时间、距离、法律、金钱数额是否穿帮？

**快查判级：**
- 任一硬伤（时间矛盾/动机断裂/伏笔断头/能力开挂）→ 标 **P0 逻辑/合理**，本集打回。
- 软伤（口吻略飘/细节微瑕）→ 标 **P2**，可后续迭代。

## 六、常见逻辑错误与对策

| 错误 | 表现 | 对策 |
|------|------|------|
| 人设崩塌 | 冷静的人突然无脑冲动 | 回扣锚点表动机弧，给行为一个可信触发 |
| 伏笔断头 | 前面埋的线索再没提 | 要么回收，要么开篇就不埋 |
| 时间线漂移 | 三天写成三个月/反之 | 建绝对时间轴，关键节点钉死 |
| 能力开挂 | 穷主角突然有无限钱 | 权力/能力边界表，新增资源必须铺垫 |
| 因果缺失 | 反派莫名放过主角 | 每个转折给足因果与动机 |
| 秒原谅/秒黑化 | 情感反应不符合人性 | 给情绪一个过程（压抑→爆发→消化） |

## 七、逻辑锚点表落地示例（片段）

```
项目：重生之棋局
核心冲突：落魄棋手顾衍重生回败局前夜，要在全国赛前揭开师父被买通的真相。
主角动机弧：03集"想赢" → 23集"想查清真相" → 53集"想守护棋道"
反派动机：师兄沈舟并非天生恶，是被债务胁迫+好胜心异化，47集有救赎伏笔
伏笔：F1 残局谱缺页(05)→回收(49)；F2 顾衍左手抖(08)→回收(55 决赛稳手)
时间线基准：故事始于"全国赛前第7天"，每日一集推进，决赛第60集
能力边界：顾衍棋力顶级但体力差；沈舟人脉广但资金受控于幕后
```
