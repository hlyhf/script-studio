# 参考 01 · 剧本格式与节奏引擎规范‌‌‌‌‌‌‌

所有原创剧本共用同一套可解析格式。本文件定义"视觉可拍性"的硬格式，是 L1 机器初检与剧本验收门禁的依据。

---

## 一、场次标题（场标）

**格式：** `X-X 时间 内外 地点`（场次编号 + 时间 + 内外 + 具体位置）

- 场次编号：`数字-数字`（如 `1-1`、`2-3`），全剧连续。
- 时间：`日` / `夜` / `晨` / `黄昏` + `内` / `外` 组合，如 `夜 内`、`日 外`。
- 人物行紧贴场景标题下一行，无空行：`人物：姓名、姓名`。

**示例：**
```
1-2 夜 外 芝加哥湖滨大道
人物：Vivienne、Dante、枪手
```

**铁律：**
- 每个场景标题**前必须有空行**（与上一动作/对白隔开）。
- 场景标题与人物行**紧贴，无空行**。
- 全文件统一 **LF 换行**（禁止 CRLF）。
- **场景标记禁用**符号**（`**1-1**`是错误的）

---

## 二、场景描述 / 动作行

- 写在人物对话之前，交代环境、角色动作、状态、音效。
- 动作行以 **`△` 开头**（红色标记，与正文区分）。
- 关键画面/运镜提示用 `▲`。

```
△暴风雪肆虐，轿车失控撞向护栏。
▲Dante转身，目光如刀。
```

---

## 三、对话行

**格式：** `角色名（情绪/动作，VO/OS）：对话内容`

- 角色名与台词**必须在同一行**（行业铁律）。
- 括号内可标情绪或动作：`（惊恐）`、`（低声，OS）`、`（冷笑）`。
- 画外音/内心独白用 `（OS）`；画外声音用 `（声）` / `（画外声）`。
- 情绪/动作括注、台词分色：人名粗体黑、台词蓝(#0070C0)、括注与▲红(#C00000)。

**示例：**
```
Vivienne（惊恐，OS）：我回来了……上一世的一切，都要重来。
陈红梅：胡说八道！恢复了又怎样？
```

---

## 四、特殊标记速查

| 标记 | 含义 | 示例 |
|------|------|------|
| `△` | 动作/画面描述行 | `△众人失惊。` |
| `▲` | 关键运镜/画面提示 | `▲苏怀瑾转身要走。` |
| `（OS）` | 画外音/内心独白 | `宁卓（OS）：有你这句话……` |
| `（声）` | 画外声音（电话/广播） | `许杰（声）：伯母，怎么了？` |
| `闪回1` / `闪回2` | 回忆场景标记 | 后接回忆内容 |
| `信息流：` | 快速信息展示 | `信息流：汤臣豪宅一套……` |
| `🔒【付费卡点】` | 本集付费/悬念卡点 | 红粗体 |
| `▶️ 下集预告：` | 结尾钩子 | 预告下一集 |

---

## 五、分集结构模板

```
## 第XX集·集标题

△（开场钩子：前100字必须有强冲突/反转/悬念）

X-1 时间 内外 地点
人物：...

△...
角色（情绪）：...

（核心事件起承转合）

🔒【付费卡点：本集最强悬念/反转】
▶️ 下集预告：...

---
*© 工作室 · 版权所有*
*创作时间：YYYY-MM-DD*
```

**单集格式清单（L1 机器初检项）：**
- [ ] 每集以 `## 第XX集·标题` 开头（无方括号）
- [ ] 每个场景头格式正确（`X-X 时间 内外 地点`，禁用**符号）
- [ ] 场景头前空行、与人物行紧贴
- [ ] 动作行用 `△`、关键画面用 `▲`
- [ ] 对话行 `角色（情绪）：台词` 同行的
- [ ] 结尾有 `🔒付费卡点` + `▶️ 下集预告`
- [ ] 全文件 LF 换行，无 CRLF
- [ ] 无 `### ` 字面残留到成品

---

## 六、节奏引擎（单集六步节拍）

每集按时间分配情绪点，保证张弛有度：

```
钩子 3s → 建立 15s → 加压 30s → 转折 20s → 兑现 20s → 留钩 10s
             （每30s一个情绪点）
```

- **黄金三秒四手法**：冲突开场 / 动作开场 / 反转开场 / 悬念开场。
- **四开篇**：身份反转 / 锚定共情 / 强共情 / 离奇设定。
- **前十集 224 爆款结构**：第 10 集放付费爆点，倒推定卡点位置。
- **卡点设计**：每集结尾 🔒 必须是本集最强悬念或反转，强度 100% 覆盖。

---

## 七、第00集信息页（剧本身份证·五段式）

文件名 `第00集_剧本信息.md`，三段式结构：

```
头部：剧名（中文+英文，居中）+ 编剧等级 + 题材 + 集数 + 每集时长
正文（五段）：
  一、剧名（中+英，不加备选名）
  二、故事题材（定位+核心看点一段话）
  三、世界观设定（时代背景+势力格局+恩怨主线）
  四、剧情简介（约200字：起因→契约→复仇→真相→结局）
  五、人物小传（只写8个主要人物，每人：身份+背景+作用）
结尾：版权行 + 创作时间
```

人物小传条目格式：
```
### 姓名（角色定位，年龄）
一句话身份 + 背景故事 + 在剧情中的作用。
```

## 八、S级五维自检（成稿前置）

| 维度 | 权重 | 硬指标 |
|------|------|--------|
| 视觉可拍性 | 25 | 动作行>70%、场景头/△/对白齐全 |
| 节奏结构 | 25 | 单集六步节拍、每30s情绪点、结尾强悬念 |
| 角色表演 | 20 | 人设口吻一致、动机清晰 |
| 冲突叙事 | 20 | 每3–5集一个小高潮、因果链闭合 |
| 工业格式 | 10 | 格式清单全过、LF统一 |

**硬指标红线：** 每集 2–3 反转、结尾强悬念、动作行占比>70%。

**投稿前置：** 首投满 30 集；完稿 80–100 集 + 大纲 + 人物小传。

---

## 九、剧本验收门禁（开工前必过，否则不进资产/分镜）

1. 格式检查（场景头/人物行/△/对白/字幕钩子全要素齐）
2. 字数评分（≥1200字/集达标，<1000字一票否决，不足走扩写）
3. 卡点比对（字幕钩子首12字去重 + 语义相似度<10%）
4. 合规扫描（血腥/下跪/迷信/肖像/水印）
5. 元数据核对（第00集 vs 剧本）

门禁不过，不进资产/分镜阶段。
