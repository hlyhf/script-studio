## 0. 三大通用结构公式（快手官方，男女频主引擎）

### 公式 1：男频 IAA/IAP - 扮猪吃虎打脸流（最主流男频引擎）
**维度组合**：现代都市 + 隐藏高手 + 大主角 + 反击翻盘 + 都市传奇 + 热血
```
【起】压迫期：主角被当众诋毁身份
【承】隐忍期：反派压迫持续升级，主角隐忍
【转】身份揭露：真实身份曝光，施压者恐慌讨好
【合】爽感收割：对方追悔莫及，主角反击翻盘
```
**核心节奏**：压迫 → 隐忍 → 掉马 → 碾压 → 后悔
**变体**：赘婿（上门女婿扮猪吃虎）、战神（兵王归来）、神医（医术碾压）、神豪（财富碾压）

```
【起】平民女主被豪门/渣男打压

【转】身份/能力揭露，打脸施压者

```
【起】女主隐藏身份，全身心投入家庭，被负心男看不起
